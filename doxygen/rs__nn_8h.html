Upload an NN model package from the Perception Service to the device. The Perception sensor must not be streaming. When the install is done the SDK resets the camera: the device disconnects and must be opened again, as after a firmware update. Firmware update on the device is refused while it installs a model, uploaded by any process. If the upload does not complete, wait a minute before resetting or reconnecting the camera: it may still be writing the model. Currently only RS2_NN_TARGET_FLASH, slot 0 and activate != 0 are supported.

Parameters
[in]deviceDevice extendable to RS2_EXTENSION_NN_LOADER
[in]filePackage content, sent as is
[in]file_sizePackage size in bytes
[in]targetWhere to store the model
[in]slotModel slot
[in]activateNon-zero to make the model the active one
[in]callbackOptional progress callback, receives values in [0, 1]
[in]client_dataPassed to the callback
[out]errorIf non-null, receives any error that occurs during this call, otherwise, errors are ignored
