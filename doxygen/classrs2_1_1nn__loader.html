Upload an NN model package, sent to the device as is. Stop the Perception sensor first. When the install is done the SDK resets the camera: the device disconnects and must be opened again, as after a firmware update. Firmware update on the device is refused while it installs a model, uploaded by any process. If the upload does not complete, wait a minute before resetting or reconnecting the camera: it may still be writing the model. Currently only RS2_NN_TARGET_FLASH, slot 0 and activate = true are supported.
